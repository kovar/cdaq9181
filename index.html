How to Use

1. Connect to your cDAQ-9181

Bridge (any browser)
Start the bridge: uv run bridge.py, then click Connect. The bridge discovers the cDAQ device, reads voltages via NI-DAQmx, and serves JSON data over WebSocket.

2. Toolbar buttons

Play / Stop
Start or stop automatic polling. Sample rate controls how often the bridge is polled (all readings go to the CSV). Plot rate controls how often the chart and display update (can be lower to keep the UI fast at high sample rates).
Record / Save
Record captures every reading with a timestamp. Save stops and downloads a CSV file with columns using the current scaling labels and units.

3. Channel Scaling

Each channel can be linearly scaled from raw voltage to engineering units. Set the label, unit, slope, and offset per channel. Formula: scaled = slope × voltage + offset. Config is saved to localStorage.

4. Chart

4 colored lines show all channels simultaneously. Click legend entries to show/hide individual channels. Window sets how much history to show. Y Min/Max lock the vertical axis. Clear erases all data and resets statistics.

5. Demo mode

Click Demo to generate fake 4-channel voltage data and try out the interface without hardware. Scaling is applied to demo data too.

6. Typical workflow

Connect → Record → Play → watch live readings and chart → Stop → Save to download CSV.

Running locally

Don't open index.html directly — ES modules need a web server. Run uv run serve.py and open http://localhost:8000.

Hardware

        
NI cDAQ-9181 chassis (1-slot, Ethernet) with NI-9215 module (4-channel, ±10V, 16-bit simultaneous sampling). The bridge uses nidaqmx to configure and read from the hardware.
